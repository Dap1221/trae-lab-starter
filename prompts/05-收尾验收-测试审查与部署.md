# 收尾验收速查卡：测试、审查与部署

## 1. 因果图法测试用例生成提示词

```markdown
你是一个资深的测试专家，精通测试领域的各种方法论。
请用「因果图法」为 `【目标代码文件路径】` 设计测试用例，规则如下：
1. 输入（因）与输出（果）的关系：恒等、非、或、与；
2. 输入之间的约束：互斥、包含、唯一、要求、屏蔽；
3. 执行步骤：
   第一步：从需求提取输入/输出，画因果图，标注关系与约束；
   第二步：由因果图生成判定表；
   第三步：判定表每行转成 1 条测试用例。
输出要求：先按三步给出简要推理，最后输出一张 Markdown 表格形式的测试用例。
```

## 2. 后端接口自动化测试提示词（pytest + httpx）

```markdown
你是资深测试开发专家（Python / FastAPI / pytest 方向）。
请根据当前项目的 FastAPI 代码，在 `tests/test_api.py` 中生成可直接运行的 pytest 接口功能测试脚本：
1. 识别全部路由与 HTTP 方法；
2. 解析 Pydantic 模型构造正常与异常请求体（含空值、类型错误、404 不存在资源）；
3. 使用 `pytest + httpx.AsyncClient + pytest-asyncio`，断言覆盖 `status_code` 和响应体关键字段。
生成后请自动执行 `pytest tests/test_api.py -v` 并报告结果；若有失败请直接定位原因。
```
